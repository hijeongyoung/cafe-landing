# cafe-landing

가상의 카페 **"카페 온기 (Cafe Ongi)"** 를 소개하는 한 페이지짜리 랜딩 페이지입니다.
별도의 빌드 도구나 라이브러리 없이 HTML과 CSS만으로 만들었습니다.

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 마크업 |
| `style.css` | 디자인 스타일 (색상, 레이아웃, 반응형) |
| `README.md` | 이 문서 |

## 페이지 구성

1. **상단 메뉴** — 로고와 소개 / 메뉴 / 오시는 길 바로가기 (스크롤해도 상단에 고정)
2. **첫 화면** — 카페 사진 배경 위에 대표 문구와 "메뉴 보기" 버튼
3. **소개** — 직접 로스팅, 매일 굽는 베이커리, 편안한 공간을 소개하는 카드 3개
4. **대표 메뉴** — 음료·베이커리 6종과 가격
5. **오시는 길** — 주소, 영업시간, 연락처
6. **하단 정보** — 저작권 표시

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 볼 수 있습니다.

## 참고

- 주소, 전화번호, 메뉴 가격은 예시로 넣은 임시 값입니다.
- 글꼴(Noto Sans KR, Noto Serif KR)은 Google Fonts에서, 첫 화면 배경 사진은 Unsplash에서 불러오므로 인터넷 연결이 필요합니다.
- 휴대폰 화면에서도 보기 좋게 반응형으로 만들었습니다.
